# Контракт програмної бібліотеки SearchUtils DLL
**Версія API:** 1.0
**Тип зв'язування:** Неявне Load-time та Явне Run-time
**ABI:** C-linkage (`extern "C"`)

## Опис
Бібліотека надає функції для пошуку елементів та збору статистики в масивах цілих чисел.
Функції безпечно опрацьовують граничні випадки (`nullptr`, некоректні розміри масивів) і не призводять до аварійного завершення програми (Crash/Access Violation).

## API Функцій

### 1. `int binarySearch(const int* arr, int size, int target)`
* **Призначення:** виконує бінарний пошук елемента `target` у відсортованому масиві.
* **Параметри:** `arr` — вказівник на масив цілих чисел, `size` — кількість елементів, `target` — шукане значення.
* **Результат:** повертає індекс знайденого елемента. Якщо елемент не знайдено, повертає `-1`.
* **Обмеження:** якщо `arr` дорівнює `nullptr` або `size <= 0`, функція безпечно завершить роботу та поверне `-1`.

### 2. `int findFirst(const int* arr, int size, int target)`
* **Призначення:** лінійний пошук першого входження елемента `target` у масиві.
* **Параметри та Обмеження:** Аналогічні `binarySearch`.
* **Результат:** повертає індекс першого знайденого елемента або `-1`, якщо елемент відсутній.

### 3. `int findLast(const int* arr, int size, int target)`
* **Призначення:** лінійний пошук останнього входження елемента `target` у масиві (пошук з кінця).
* **Параметри та Обмеження:** Аналогічні `binarySearch`.
* **Результат:** повертає індекс останнього знайденого елемента або `-1`, якщо елемент відсутній.

### 4. `int countOccurrences(const int* arr, int size, int target)`
* **Призначення:** підраховує загальну кількість входжень елемента `target` у масиві.
* **Параметри:** Аналогічні `binarySearch`.
* **Результат:** повертає кількість входжень (від `0` і більше).
* **Обмеження:** якщо `arr` дорівнює `nullptr` або `size <= 0`, функція безпечно поверне `0`.

### 5. `int kthElement(int* arr, int size, int k)`
* **Призначення:** знаходить `k`-тий за найменшою величиною елемент у масиві. Увага: масив буде частково відсортовано (змінено).
* **Параметри:** `arr` — вхідний масив, `size` — кількість елементів, `k` — індекс шуканого елемента у відсортованому вигляді (починаючи з 0).
* **Результат:** повертає значення `k`-того елемента.
* **Обмеження:** якщо `arr` дорівнює `nullptr`, `size <= 0`, або `k` виходить за межі (`k < 0` або `k >= size`), функція безпечно завершить роботу та поверне `-1`.

## Керування пам'яттю
Бібліотека не виділяє динамічну пам'ять. Користувач несе повну відповідальність за виділення та звільнення пам'яті для масивів, що передаються у функції.
