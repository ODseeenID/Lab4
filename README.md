# Контракт програмної бібліотеки ArrayUtils DLL
**Версія API:** 1.0
**Тип зв'язування:** Неявне Load-time та Явне Run-time
**ABI:** C-linkage (`extern "C"`).

## Опис
Бібліотека надає функції для сортування та аналізу масивів цілих чисел.
Функції безпечно опрацьовують граничні випадки (`nullptr`, некоректні розміри масивів) і не призводять до аварійного завершення програми

## API Функцій

### 1. `void quickSort(int* arr, int size)`
* **Призначення:** швидке сортування масиву.
* **Параметри:** `arr` - вказівник на масив цілих чисел, `size` - кількість елементів
* **Обмеження:** якщо `arr` дорівнює `nullptr` або `size <= 1`, функція безпечно завершить роботу без змін масиву

### 2. `void mergeSort(int* arr, int size)`
* **Призначення:** сортування злиттям (стабільне сортування)
* **Параметри та Обмеження:** Аналогічні `quickSort`

### 3. `void heapSort(int* arr, int size)`
* **Призначення:** пірамідальне сортування
* **Параметри та Обмеження:** Аналогічні `quickSort`

### 4. `bool isSorted(const int* arr, int size)`
* **Призначення:** перевіряє, чи відсортовано масив за зростанням
* **Результат:** Повертає `true`, якщо масив відсортовано або передано `nullptr` або масив з 0 чи 1 елементом. Інакше `false`

### 5. `void findExtremes(const int* arr, int size, int* minVal, int* maxVal)`
* **Призначення:** знаходить мінімальне та максимальне значення в масиві
* **Параметри:** `arr` - вихідний масив, `minVal` та `maxVal` - вказівники на змінні для запису результату.
* **Обмеження:** Якщо хоча б один вказівник дорівнює `nullptr` або `size <= 0`, функція безпечно завершить роботу без запису результатів

## Керування пам'яттю
Бібліотека не виділяє динамічну пам'ять. Користувач несе повну відповідальність за виділення та звільнення пам'яті для масивів, що передаються у функції
